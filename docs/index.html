Karantin ID uchun native Face ID kirish

Webview ichidagi skanerni almashtiruvchi on-device kamera + yuz aniqlash paketi: to'liq authorize → tasdiqlash oqimini bajaradi va ilovangizga OAuth codeini qaytaradi.

on-device ML Kit passiv liveness rasm siqish iOS + Android

Umumiy

Ilovaning Karantin ID kirishi avval butun yuz-skaner web sahifasini webview ichida yuklardi — u yerda Face ID va kameraga kirish ishonchsiz ishlardi. karantin_face_sdk bu oqimni Flutterga ko'chiradi: old kamerani ochadi, yuzni qurilmada aniqlaydi, uni oladi, rasmlarni rasmiy Karantin ID backendiga yuboradi, OAuth redirect zanjirini kuzatadi va avtorizatsiya kodini qaytaradi.

Faqat tasdiqlash rasmlari rasmiy id.karantin.uz backendiga ketadi. Yuz ma'lumoti boshqa hech qayerga yuborilmaydi.

Imkoniyatlar

On-device aniqlash Google ML Kit yuzni qurilmada topadi va kadrlaydi — hech narsa tashqariga oqmaydi.
Passiv liveness Tabiiy harakat, ko'z pirpirashi va bosh burchagi — burilish yoki pirpiratish so'ralmaydi.
Aqlli capture Eng o'tkir kadrni tanlaydi, rasmlarni siqadi — zaif internetda ham yuklama kichik qoladi.
Anti-fraud bog'lanish Har bir tasdiqga device id, fingerprint va GPS biriktiriladi.
Native dialoglar Kamera-ruxsat so'rovi iOS'da Cupertino, Android'da Material ko'rinishida.
Moslashuvchan Client id, redirect URI, base URL, aksent rang va barcha matnlar.

Qanday ishlaydi

  1. GET /app/project/oauth/authorize — redirectdan token / name (yoki code / state) olinadi.
  2. Passport / PNFL + yuz skaneri — identifikator kiritiladi, so'ng yuz qurilmada olinadi.
  3. POST /app/project/oauth/{login,register,verify-doc} — face_image + check_image1..4 + qurilma maydonlari yuklanadi.
  4. redirect_to kuzatiladi — zanjir redirectUri?code=… ga yetguncha boriladi va kod qaytariladi.

So'rovlar orasida bitta cookie jar ulashiladi — OAuth sessiyasi bitta brauzer sessiyasidek ishlaydi.
